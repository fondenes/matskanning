# Matskanning
Programmet lar deg registrere matvarer og viser hvor lenge det er til disse går ut på dato.

**Nedlastning:**

Last ned nyeste versjon under [releases](https://github.com/fondenes/matskanning/releases/latest).

**Bruk av appen:**

Registrer matvarer ved å trykke på den grønne "legg til"-knappen. Deretter skriver du inn navnet på matvaren, og legger til utløpsdato på oppgitt format (åååå-mm-dd).
Fjern matvarer du har spist opp/kastet ved å huke av boksen ved siden av matvaren.
Programmet oppdateres og lagres automatisk med en gang man har lagt til eller fjernet en matvare.
